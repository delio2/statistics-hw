Homework 4 - Welford's recurrence formulas, sampling mean and variance

Exercise 1: recurrences for the sum of squares and the variance, with the code. Exercise 2: averages of the sampling means and variances of m hackers.

Exercise 1 - Welford's recurrence formulas

The values x1, x2, ... arrive one at a time. After k values, Mk = (x1 + ... + xk)/k is their mean, SSk = Σi=1..k (xi − Mk)² is the sum of squares of the deviations from the mean, and sk² = SSk/(k − 1), for k ≥ 2, is their (sampling) variance. The aim is to update them from the results at step k − 1 and the new value xk only, without storing the values.

Knuth's recurrence for the mean

The approach: write the quantity at step k through the same quantity at step k − 1 and the new value. The sum of the first k values is the sum of the first k − 1 values plus xk, so

k Mk = (k − 1) Mk−1 + xk  ⇒  Mk = Mk−1 + (xk − Mk−1)/k   (1)

which can also be written k (Mk − Mk−1) = xk − Mk−1  (1').

Welford's recurrence for the sum of squares

The same approach for SSk. Expanding the square gives SSk = Σ xi² − k Mk², hence

SSk − SSk−1 = xk² − k Mk² + (k − 1) Mk−1².

Since (k − 1) Mk−1 = k Mk − xk, the last term is (k Mk − xk) Mk−1, and

SSk − SSk−1 = xk (xk − Mk−1) − k Mk (Mk − Mk−1) = xk (xk − Mk−1) − Mk (xk − Mk−1),

where the last step uses (1'). Therefore

SSk = SSk−1 + (xk − Mk−1)(xk − Mk),   SS1 = 0   (2)

Welford's recurrence for the variance

By (1), xk − Mk = (xk − Mk−1) − (Mk − Mk−1) = (k − 1)/k · (xk − Mk−1), so (2) is also SSk = SSk−1 + (k − 1)/k · (xk − Mk−1)². Dividing by k − 1, and using SSk−1/(k − 1) = (k − 2)/(k − 1) · sk−1²:

sk² = (k − 2)/(k − 1) · sk−1² + (xk − Mk−1)²/k,   k ≥ 2   (3)

(for k = 2 it gives s2² = (x2 − x1)²/2). In the code it is enough to keep SSk and divide it by k − 1 when the variance is needed.

The code

Only k, M and SS are stored. Starting from k = 0, M = 0 and SS = 0, each new value x costs the 3 lines of the core logic: the difference xk − Mk−1, the new mean by (1) and the new sum of squares by (2) (after the update, x - state.mean is xk − Mk). The code (js/welford.js):

// Welford's recurrences: update the state (k, mean, ss) with the next value x. The core logic is the 3 lines below
function update(state, x) {
  const delta = x - state.mean;                    // x_k - M_(k-1)
  state.mean += delta / ++state.k;                 // M_k = M_(k-1) + (x_k - M_(k-1)) / k                 (Knuth)
  state.ss += delta * (x - state.mean);            // SS_k = SS_(k-1) + (x_k - M_(k-1)) (x_k - M_k)       (Welford)
}
// the (sampling) variance of the values seen so far, for k >= 2
const variance = (state) => state.ss / (state.k - 1);

Exercise 2 - Sampling mean and variance

As in Homework 3, m hackers go through n systems, but now each penetration attempt gets a score between 0 and 10. The scores are drawn from a fixed distribution: the uniform distribution on the integers 0, 1, ..., 10 (each value has probability 1/11). Its theoretical mean is μ = (0 + 10)/2 = 5 and its theoretical variance is σ² = ((10 − 0 + 1)² − 1)/12 = 10.

Each hacker receives one score for each system, a trajectory of n scores. For each hacker the sampling mean and the sampling variance of its n scores are computed with Welford's recurrences (the scores are used as they are generated, they are never stored). Then the m sampling means and the m sampling variances are averaged (their standard deviation across the hackers is computed with the same recurrences). I use m = 1,000 hackers and n = 10, 100, 1,000 and 10,000 (js/welford.js):

// the score of one penetration attempt: an integer between 0 and 10, uniform on {0, 1, ..., 10}.
// Its theoretical mean is (0 + 10) / 2 = 5 and its theoretical variance is ((10 - 0 + 1)^2 - 1) / 12 = 10
const MU = 5, SIGMA2 = 10;
const score = () => Math.floor(Math.random() * 11);

// one hacker attacks n systems: the sampling mean and the sampling variance of its n scores
function hacker(n) {
  const state = { k: 0, mean: 0, ss: 0 };
  for (let i = 0; i < n; i++) update(state, score());
  return { mean: state.mean, variance: variance(state) };
}

// m hackers: the average and the standard deviation, across the hackers, of the sampling means and of
// the sampling variances (computed with the same recurrences)
function experiment(n, m) {
  const means = { k: 0, mean: 0, ss: 0 }, variances = { k: 0, mean: 0, ss: 0 };
  for (let j = 0; j < m; j++) {
    const h = hacker(n);
    update(means, h.mean);
    update(variances, h.variance);
  }
  return {
    n,
    avgMeans: means.mean, sdMeans: Math.sqrt(variance(means)),
    avgVariances: variances.mean, sdVariances: Math.sqrt(variance(variances)),
  };
}

Comparison with μ and σ². In every row the average of the sampling means is very close to μ = 5 and the average of the sampling variances is very close to σ² = 10. The small differences are the simulation error, which shrinks like 1/√m.

Conclusions. On average the sampling mean hits μ and the sampling variance hits σ², whatever the number n of scores of a hacker: the sampling mean and the sampling variance are unbiased estimators, E[x̄] = μ and E[s²] = σ². For the variance this holds because of the divisor n − 1: the sum of squares SS has expected value (n − 1)σ², so dividing by n would give a variance that is too small by the factor (n − 1)/n on average.

Why this is useful in inferential statistics. The parameters μ and σ² of a population are normally unknown and only one sample is available (here, the n scores of one hacker). The sample mean and the sample variance of that single sample are on target on average, with no systematic error, so they can be used as estimates of the unknown μ and σ². The spread across the hackers (the last two columns) tells how far a single sample can be from the target, which is the basis of standard errors, confidence intervals and tests.

Effect of n on the variability. Increasing n does not move the averages (they stay at μ and σ²) but reduces the variability: the standard deviation of the sampling means falls like σ/√n, because Var(x̄) = σ²/n (100 times more systems give about 10 times less variability), and the standard deviation of the sampling variances falls at about the same rate (its variance is of order 1/n). With more systems per hacker, each sampling mean and each sampling variance is closer to μ and σ²: the estimators are consistent.
