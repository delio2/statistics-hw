Homework 3 - Penetration scores of n systems and m attackers

Law of large numbers and central limit theorem on simulated trajectories (Bernoulli and Rademacher models).

m attackers go through n systems and get a penetration score on each one. I model the score of an attacker as a sum of independent increments, simulate many trajectories, and look at how the total, the average and the normalized total score behave when n grows.

1. The model

An attacker goes through the systems one after the other. At step i it gets the penetration score Xi on system i, and the increments X1, X2, ... are independent and identically distributed. After k systems its score is Sk = X1 + ... + Xk, and the sequence S1, S2, ... is the trajectory of the attacker. The m attackers are independent, so they give m independent trajectories.

The three quantities are the total score Sn, the average score Sn/n and the normalized total score Sn/√n. Because the increments are independent, E[Sn] = nμ and Var(Sn) = nσ², hence Var(Sn/n) = σ²/n and Var(Sn/√n) = σ².

2. The simulation

Each of the m attackers goes through N = 10,000 systems. The values of n are 10, 100, 1,000 and 10,000, and Sn is read from the same trajectory at step n (js/sums.js). I use m = 1,000 attackers and p = 0.3 for the Bernoulli model: with m = 1,000 the simulated variances and frequencies are accurate to a few percent (the error shrinks like 1/√m) and the histograms are smooth.

// m attackers, each one goes through N systems (N = the largest n). S[k][j] is the total score S_n
// of attacker j for n = ns[k], read from its trajectory. The whole trajectory is kept for the
// first `keep` attackers (for the picture)
async function simulate(model, m, ns, keep) {
  const N = ns[ns.length - 1], S = ns.map(() => new Float64Array(m)), paths = [];
  for (let j = 0; j < m; j++) {
    const path = j < keep ? new Int32Array(N + 1) : null;
    let s = 0, k = 0;
    for (let i = 1; i <= N; i++) {
      s += model.draw();                                   // score on system i
      if (path) path[i] = s;
      if (i === ns[k]) S[k++][j] = s;
    }
    if (path) paths.push(path);
    if (j % 200 === 199) await new Promise((r) => setTimeout(r, 0));   // let the page update
  }
  return { S, paths };
}

From the m values of Sn I compute the three quantities and one row of the tables:

// the three quantities studied, for the m attackers: S_n, S_n/n and S_n/sqrt(n)
const quantities = (S, n) => ({
  total: S, average: S.map((x) => x / n), normalized: S.map((x) => x / Math.sqrt(n)),
});

const EPS = 0.05;

// one row of the tables, for one value of n: the frequency of |S_n/n - mu| > EPS
// and the variances of the three quantities (simulated and from theory)
function summarize(model, S, n) {
  const q = quantities(S, n);
  return {
    n,
    farFromMu: q.average.filter((x) => Math.abs(x - model.mu) > EPS).length / S.length,
    varTotal: variance(q.total), varAverage: variance(q.average), varNormalized: variance(q.normalized),
    theory: { varTotal: n * model.sigma2, varAverage: model.sigma2 / n, varNormalized: model.sigma2 },
  };
}

3. Sample trajectories

15 of the m trajectories for each model.

  • Bernoulli: the trajectories grow almost linearly in a narrow band around p·k. The total score is mostly drift, and the random fluctuation (of order √k) is small compared with it.
  • Rademacher: there is no drift. The trajectories are symmetric random walks around 0 that spread out like √k.

Law of large numbers. Sn/n converges in probability to μ: for every ε > 0, P(|Sn/n − μ| > ε) goes to 0. The second column of the tables is the simulated value of this probability for ε = 0.05. It decreases toward 0 as n grows, and the histograms of the average score collapse onto μ.

Variance under the different normalizations. Var(Sn) = nσ² grows linearly: the total score spreads out. Var(Sn/n) = σ²/n goes to 0: all the attackers end up with almost the same average. Only Var(Sn/√n) = σ² stays constant, so √n is the scale that keeps a distribution that is neither spreading out nor collapsing. The simulated variances in the tables agree with these values within the sampling error.

Central limit theorem (Rademacher model). Sn/√n has mean 0 and variance 1 for every n, and it converges in distribution to the standard normal N(0, 1): the histograms in the last row follow the density of N(0, 1) (the black line) more and more closely as n grows. In the Bernoulli model Sn/√n has mean p√n, which grows with n, so it has no limit.

6. Interpretation: systems and attackers

A trajectory is one attacker moving through the systems. In the Bernoulli model Sk counts the systems penetrated among the first k, and Sn/n is the fraction of the n systems that the attacker compromises. In the Rademacher model Sk is a net score that goes up and down with equal probability.

  • System size n. The expected total score grows like nμ but its fluctuations only like σ√n, so the relative fluctuation (σ/(μ√n) in the Bernoulli model) shrinks like 1/√n. With few systems the result depends on luck: the fractions of penetrated systems of different attackers are very spread out (n = 10). With many systems every attacker penetrates almost exactly a fraction p of them, and the outcome is predictable (law of large numbers). In the symmetric model the net score has no drift, but its spread still grows like √n.
  • Number of attackers m. The attackers are independent, so m does not change the distribution of the score of one attacker. It sets how many trajectories we observe (the precision of the simulated distributions grows like √m) and the aggregate score of all the attackers, T = Sn(1) + ... + Sn(m), a sum of mn independent increments: E[T] = mnμ and Var(T) = mnσ². The expected aggregate score grows with both m and n, while its relative fluctuation shrinks like 1/√(mn): with many attackers and many systems the total number of penetrations is almost deterministic. In the symmetric model the aggregate stays centred at 0, with a spread of order √(mn).
